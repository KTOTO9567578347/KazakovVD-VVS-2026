Репозиторий В.Д.Казакова (группа БПМ-26-6-3) для выполнения ДЗ по введению в спецальность. 

Структура:

DZ1/ - первое ДЗ (соответственно варианты калькулятора с 1 по 4 в том порядке, как были названы на лекции 12.10.26)

DZ2/ - ДЗ про пять уровней работы со строками

DZ3/ - Игра на массивах. Потребуется создать venv при развёртывании, и установить в него requirements.txt. Пуск игры через python main.py. Игра тестировалась в интегрированном терминале VSCode, а также в gnome-terminal. В игре T для меню команд, help для помощи.

DZ4/ - Датасет "Титаник"

DZ5/ - интерфейсы, создайте venv, устновите venv, из него запускайте interface_qt.py и interface_tk.py (если ругается проблема 100% у вас в системе, на Linux Ubuntu помогло GDK_BACKEND=x11 python interface_qt.py)
